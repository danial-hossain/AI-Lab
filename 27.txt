# Q3. Manhattan Distance

Question অনুযায়ী:

* 8-puzzle
* Manhattan distance
* state হবে **list of tuples**
* goal/current নিজের নেওয়া
* **global variables** দিয়ে function state নেবে

এই code লিখতে পারো:

```python
# Goal state
goal = [
    (1, 0, 0),
    (2, 0, 1),
    (3, 0, 2),
    (4, 1, 0),
    (5, 1, 1),
    (6, 1, 2),
    (7, 2, 0),
    (8, 2, 1)
]


# Current state
current = [
    (1, 0, 0),
    (2, 0, 1),
    (3, 0, 2),
    (4, 1, 0),
    (5, 2, 1),
    (6, 1, 2),
    (7, 2, 0),
    (8, 2, 2)
]


def heuristic():

    distance = 0

    for i in range(len(current)):

        tile = current[i][0]

        current_row = current[i][1]
        current_col = current[i][2]


        for j in range(len(goal)):

            if goal[j][0] == tile:

                goal_row = goal[j][1]
                goal_col = goal[j][2]

                distance = distance + abs(current_row - goal_row)
                distance = distance + abs(current_col - goal_col)

                break

    return distance


answer = heuristic()

print("Manhattan Distance:", answer)
```

### এখানে tuple-এর meaning:

```text
(tile, row, column)
```

যেমন:

```python
(5, 2, 1)
```

মানে:

```text
Tile 5
Row 2
Column 1
```

### Calculation

আমাদের current আর goal-এর মধ্যে:

```text
Tile 5 → 1 ঘর দূরে
Tile 8 → 1 ঘর দূরে
```

তাই:

```text
Manhattan Distance = 2
```

Output:

```text
Manhattan Distance: 2
```

# Q4. Nth element of the tail

Given `nthel()`:

```prolog
nthel(N, [_|T], E) :-
    N1 is N - 1,
    nthel(N1, T, E).

nthel(1, [H|_], H) :- !.
```

Question বলছে:

> input list-এর **head-এ n থাকবে**, আর tail-এর n-th element বের করতে হবে।

তাই:

```text
Input:
[3, 10, 20, 30, 40]

Head = 3
Tail = [10, 20, 30, 40]

Tail-এর 3rd element = 30
```

### Program:

```prolog
factorial(0, 1) :- !.

factorial(N, F) :-
    N > 0,
    N1 is N - 1,
    factorial(N1, F1),
    F is N * F1.


nthel(N, [_|T], E) :-
    N1 is N - 1,
    nthel(N1, T, E).

nthel(1, [H|_], H) :- !.


find_element([N|T], E) :-
    nthel(N, T, E).
```

### Query:

```prolog
?- find_element([3,10,20,30,40], E).
```

Process:

```text
Head = 3
Tail = [10,20,30,40]

nthel(3, [10,20,30,40], E)

↓ 10 বাদ
nthel(2, [20,30,40], E)

↓ 20 বাদ
nthel(1, [30,40], E)

↓
E = 30
```

### Answer:

```text
E = 30.
```
