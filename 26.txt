না ভাই, **এখানেই আসল confusion**। তুমি `N = 0` আর `F1 = 0` এক করে ফেলছো। দুটো এক জিনিস না।

Code:

```prolog
factorial(0, 1) :- !.

factorial(N, F) :-
    N > 0,
    N1 is N - 1,
    factorial(N1, F1),
    F is N * F1.
```

ধরো:

```prolog
?- factorial(4, F).
```

### একদম শেষে কী হয় দেখো

আমরা যখন নিচে যাই:

```text
4 → 3 → 2 → 1 → 0
```

যখন `N = 0` হয়, তখন **এই rule** কাজ করে:

```prolog
factorial(0, 1).
```

অর্থাৎ:

```text
N = 0
F = 1
```

**এখানে `0 × 1` হচ্ছে না।**

কারণ `N > 0` false হয়ে গেছে, তাই recursive rule:

```prolog
factorial(N, F) :-
    ...
    F is N * F1.
```

এটা আর চালু হচ্ছে না।
